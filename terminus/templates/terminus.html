                privacy_tip
                Before enabling the Assistant
            

            

                The Assistant reads your live session output and can
                propose commands to run on your devices.
                Please read this carefully — it is not the same as a chat window.
            

            
    
                
  • Session output is sent to the provider you
                    configure. Passwords, keys, community strings and
                    certificates are masked first; hostnames,
                    IPs, interface names, configuration and command output are
                    sent as-is.
                
    • 
                
  • Nothing runs without your approval. Every
                    command is shown to you first, per device, and you can edit
                    or reject it.
                
    • 
                
  • Only read-only commands are permitted.
                    Configuration changes, reloads, clears and file operations
                    are refused by Terminus before you are even asked.
                
    • 
                
  • Command output is sent back to the provider
                    so it can answer. Every command it runs is written to your
                    session log.
                
    • 
                
  • Choose a provider your organisation permits, and use a
                    capable model — small models propose wrong commands.
                
    • 
                
  • Model output can be wrong. You remain
                    responsible for what runs on your infrastructure.
